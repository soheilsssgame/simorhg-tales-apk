> **حافظهٔ کار این پروژه روی گیت‌هاب است، نه ورک‌اسپیس.**  
> هر فاز باید در همین ریپو سند + ریلیز APK داشته باشد.  
> تاریخ سند: ۲۰۲۶-۰۸-۳۰ | وضعیت فعلی: **v0.6.0-alpha** (APK ≈ ۴٫۸ مگ)

## ۰) تشخیص صادقانهٔ وضعیت فعلی

v0.6 یک لایهٔ «حس عمق» اضافه کرد (زمین پرسپکتیو، سایه، پارالاکس، زوم دوربین) اما **هنوز بازی نیست** — یک پوستر متحرک با نوارهای ویجتی است.

| شکایت تو | علت ریشه‌ای در v0.6 |
|---|---|
| زمین بک‌گراند را پوشانده | زمین overlay بزرگ + افق پایین؛ لایهٔ میانی جو/مه کم است |
| کاراکترها انیمیشن حمله ندارند | ترنسفورم (چرخش/اسکیل/ترجمه) روی **یک فریم استاتیک** — نه اسپریت‌شیت |
| مکانیک خوب نیست / استراتژی چیپ نیست | نبرد هنوز «نوبت + یک QTE» است؛ انتخاب معنادار کم است |
| منو شبیه سایت است | Material/Cupertino + ایموجی به‌جای HUD بازی |
| ۴ تا جلو به‌جای ۳ + دو تا افتاده روی هم | قانون فورمیشن قفل نشده؛ overlap بدون z-sort پایدار |
| دشمن‌های بالا روی هوا | لنگر پا به زمین پرسپکتیو وصل نیست (anchor اشتباه) |
| اتمسفر عکس ساده | بدون مه، نور حجمی، ذرات محیطی، LUT، صدای فضا |
| کارت پاورآپ + مانا نیست | سیستم کارت اصلاً وجود ندارد |
| HUD حمله شبیه سایت | دکمه‌های متنی/ایموجی، نه آیکون حکاکی‌شده |
| حرکت = چرخش | بدون cycle راه رفتن / wind-up / follow-through |
| حس عکس بودن | بدون تماس پا با خاک، بدون وزن، بدون silhouette خوانا |
| دشمن بدون ability سینمایی | AI ساده + یک اتک |
| حجم APK کم (~۴٫۸MB) | تقریباً بدون اسپریت‌شیت، بدون صدا/موسیقی واقعی، تصاویر فشردهٔ کم‌رزولوشن |

**حجم کم = باگ نیست، کمبود محتواست.** بازی‌های مشابه موبایل:

- AFK Arena / RAID: ده‌ها مگ فقط آرت + انیم
- Slay the Spire موبایل: کارت‌آرت جدا
- هدف سالم برای آلفأ غنی: **۲۵–۶۰ MB** (اسپریت، SFX، موسیقی حلقه‌ای، کارت‌آرت)

الگوهای مرجع (نه کپی):
- **نبرد واکنشی:** Clair Obscur Expedition 33 (dodge گشاد / parry تنگ / AP از دفاع)
- **فورمیشن ۵ قهرمان:** AFK Arena (۳ جلو / ۲ عقب یا ۴+۱ باس)
- **کارت + مانا پایین صفحه:** Hearthstone / Slay the Spire (قوس کارت، هاور بزرگ، هزینه گوشه)
- **HUD بازی نه سایت:** Darkest Dungeon / Octopath (قاب فلزی، بدون ایموجی)

## ۱) اصول غیرقابل‌مذاکره (هر PR باید پاس کند)

1. **هیچ ایموجی در UI بازی.** فقط آیکون وکتور/حکاکی (حمله، دفاع، تنظیمات، خودکار، مانا).
2. **هیچ کاراکتری روی هوا.** پای هر موجود روی صفحهٔ زمین پرسپکتیو؛ سایه دقیقاً زیر پا.
3. **فورمیشن بازیکن حداکثر ۳ جلو + ۲ عقب** (۵ اسلات). هیچ هم‌پوشانی غیرمجاز.
4. **حمله = انیمیشن چندفریم** (حداقل idle / wind-up / lunge / impact / recover). چرخشِ تک‌فریم ممنوع.
5. **تصمیم استراتژیک در هر نوبت:** هدف، کارت/مهارت، دفاع پیش‌دستانه، یا ذخیرهٔ مانا.
6. **دشمن = الگو + تلگراف + حداقل یک ability ویژه با انیمیشن.**
7. **اتمسفر = لایه‌ها:** آسمان / مه دور / سیلوئت میانی / میدان / ذرات پیش‌زمینه / درجهٔ رنگ بایوم.
8. **زمین حداکثر ۳۵٪ ارتفاع پایین صفحه**؛ بک‌گراند باید دیده شود.
9. **همهٔ دارایی‌ها در گیت‌هاب ریلیز** (سند + APK). ورک‌اسپیس حافظه نیست.
10. **تست خودکار** برای فورمیشن، مانا، کارت، و «پا روی زمین».

```
┌─────────────────────────────────────────────┐
  آسمان + مه + پارالاکس (۶۰–۶۵٪ بالا)
├─────────────────────────────────────────────┤
  میدان: ۵ اسلات بازیکن (L) | ۵ اسلات دشمن (R)
  خط افق نازک · سایه‌ها · ذرات خاک
├────────────── HUD نبرد ─────────────────────┤
  پرترهٔ نوبت · نوار مانا ◆◆◆◆ · AP
├────────── قوس کارت‌ها (پایین) ──────────────┤
  ۵–۷ کارت در دست · هزینه گوشه · کشیدن روی هدف
└─────────────────────────────────────────────┘
```

### اقتصاد منابع (استراتژی واقعی)

| منبع | تولید | مصرف | نقش |
|---|---|---|---|
| **مانا (۰–۱۰)** | +۱ اول هر نوبت بازیکن (سقف با ارتقا) | بازی کردن کارت | انتخاب «حالا یا بعد» |
| **AP موجود** | حمله پایه +۱، پری کامل +۱، کارت خاص | مهارت شخصی قهرمان | هویت کلاس |
| **استقامت دفاع** | پر شدن آرام | Dodge رایگان، Parry ریسک/پاداش | مهارت دستی |
| **نیت دشمن (Intent)** | هر نوبت نشان داده می‌شود | — | خواندن و واکنش |

الگوی Expedition 33 را **کورکورانه کپی نکن**:  
- Dodge پنجرهٔ گشاد، صفر آسیب، **بدون** AP  
- Parry پنجرهٔ تنگ، صفر آسیب + AP + کانتر اگر کل کمبو را بگیری  
- اگر Parry بیش از حد قوی شد (مثل نقدهای E33)، کانتر آسیب متوسط بدهد نه وین‌باتن.

### چیپ استراتژیک اجباری

هر نبرد حداقل یکی از این‌ها را بخواهد:
- پیرس زره / ضدسپر
- کنترل (stun, silence, pull به جلو)
- پاک‌کردن debuff
- burst در پنجرهٔ Break
- قربانی کردن یک اسلات عقب برای حفظ تانک جلو

اگر همهٔ کارت‌ها «آسیب بیشتر» باشند، استراتژی نیست.

## ۳) فورمیشن و همپوشانی (اولویت P0 — قبل از هر آرت جدید)

### قانون اسلات

بازیکن:
```
عقب:  [R1] [R2]
جلو:     [F1] [F2] [F3]
```
دشمن آینه.

- **فقط ۳ واحد جلو.** اگر ۴ قهرمان جلو گذاشتی، سیستم باید **رد کند** یا آخرین را به عقب هل بدهد.
- z-order: جلو > عقب؛ داخل یک ردیف y پایین‌تر روی y بالاتر رسم شود.
- حداقل فاصلهٔ افقی = ۶۰٪ عرض اسپریت.
- «افتادن روی هم» = باگ P0؛ تست طلایی: هیچ دو hitbox مرکزی نزدیک‌تر از آستانه.

### لنگر به زمین

- هر موجود `footAnchor` دارد.
- `groundY = perspectiveLine(row, col)` — ردیف عقب بالاتر و کوچک‌تر.
- دشمنان ردیف دور **روی هوا نیستند**؛ روی کاشی دور ایستاده‌اند.

## ۴) انیمیشن واقعی (نه چرخش)

حداقل سیکل برای **هر** قهرمان و دشمن:

| کلیپ | فریم پیشنهادی | حس |
|---|---|---|
| idle | ۸–۱۲ | تنفس، پارچه، سلاح کمی نوسان |
| walk/step | ۶ | فقط هنگام جابه‌جایی اسلات |
| wind-up | ۴–۶ | جمع شدن وزن عقب |
| attack lunge | ۶–۱۰ | پا از زمین جدا، squash، رد سرعت |
| impact | ۲–۳ hold | hit-stop جهان |
| recover | ۴ | برگشت به idle |
| hurt | ۴ | knockback + flash نه فقط tint |
| death | ۸–۱۲ | سقوط روی زمین نه fade |
| skill/ult | ۱۲–۲۰ | لایهٔ VFX جدا |
| cast (دشمن) | تلگراف رنگی | بازیکن وقت خواندن دارد |

پیاده‌سازی پیشنهادی:
1. کوتاه‌مدت: **sprite sheet** روی همان پرتره‌ها با deformation کنترل‌شده + ۲–۳ فریم AI-generated consistent
2. میان‌مدت: **Rive / Spine** اسکلتی (وزن واقعی شانه و پا)
3. VFX حمله جدا از بدن: اسلش، آتش، خاک، شوک‌ویو

ضربه باید **روی فریم impact** ثبت شود نه وسط tween.

## ۵) زمین و اتمسفر (رفع «پوشاندن بک‌گراند»)

- ارتفاع زمین را **کم کن** (هدف: ۲۵–۳۵٪ پایین).
- زمین از لبهٔ پایین **محو شود به مه** نه یک مستطیل مات.
- بک‌گراند ۳→۵ لایه: آسمان، کوه دور (حرکت خیلی کم)، درخت/ویرانه میان، میدان، ذرات نزدیک.
- هر بایوم: LUT رنگ + ذرات (خاک شاهنامه، برگ البرز، خاکستر دوزخ، برف مازندران).
- نور: rim light روی سیلوئت‌ها مخالف آسمان تا «عکس بریده» نباشند.
- تماس پا: غبار هنگام فرود، ترک کوچک روی خاک هنگام اولت.

## ۶) سیستم کارت پاورآپ (ویژگی ستارهٔ v0.8)

### قوانین

- دست شروع: ۵ کارت. سقف دست: ۷.
- هر نوبت: +۱ کارت (تا سقف) و +۱ مانا (تا سقف ۱۰).
- کارت‌ها روی **قوس پایین** مثل Hearthstone؛ لمس = بزرگ‌نمایی؛ درگ روی هدف = اجرا.
- هزینه مانا گوشهٔ بالا-راست کارت با عدد حکاکی نه ایموجی.

### ستون‌های کارت (حداقل ۴۸ کارت در v0.8، هدف ۹۶ تا v1.0)

**آسیب:** ضربهٔ منفرد، چندضربه، AoE خط جلو، اعدام زیر ۳۰٪.  
**دفاع:** سپر یک نفر، سپر گروهی، تاونت، ضدحمله.  
**کنترل:** stun یک نوبت، pull عقب→جلو، silence مهارت، کاهش سرعت نوبت.  
**باقی:** هیل، پاک‌سازی، لوت مانا، رسم کارت.  
**ساختاری:** «این نوبت کارت‌ها ۱ مانا ارزان‌تر»، «اگر پری کردی این کارت رایگان».  
**اسطوره‌ای شاهنامه:** سیمرغ (ریوایف یک‌بار در جنگ)، رستم-هفت‌خان (استک با مرحله)، دیو سپید (مه که دقت QTE را کم می‌کند — برای دشمن).

هر کارت: نام پارسی، هزینه، تایپ، متن یک خطی، آرت اختصاصی، VFX اجرا.

**کارت دشمن ندارند در دست تو** — دشمن ability دارد که مثل کارت تلگراف می‌شود (آیکون بالای سر).

## ۷) دشمنان — الگو + هویت

هر خانوادهٔ دشمن:

1. Intent قابل خواندن (حمله / AoE / بافر / شارژ)
2. تلگراف ۱٫۵–۲ ثانیه قبل از ضربه
3. **یک ability امضا** با انیمیشن اختصاصی
4. مقاومت/ضعف عنصری (آتش، ظلمت، مقدس، فیزیکی)
5. برای نخبه/باس: فاز ۲ در ۵۰٪ جان + تغییر الگوی پری

نمونهٔ توانایی‌ها:
- کماندار دور: «باران تیر» — باید Jump/Dodge چندضربه
- دیو زره‌پوش: «دیوار» — تا پیرس نزنی آسیب ۱ می‌شود
- جادوگر: «نفرین مانا» — سقف مانا را ۲ نوبت کم می‌کند
- باس: کمبوی ۸ ضربه با فیک؛ پری کامل = کانتر سینمایی

دشمنان پرنده فقط اگر **گونهٔ پرنده** باشند؛ و آن‌ها روی لایهٔ مشخص با سایهٔ بزرگ روی زمین.

## ۸) HUD و منوها — «بازی» نه «سایت»

حذف کامل ایموجی از:
- دکمهٔ خودکار
- تنظیمات
- مهارت‌ها
- وضعیت‌ها
- پیام‌های توست

جایگزین: ست آیکون یکدست (خط پارسی-اسطوره‌ای: سپر، شمشیر، چرخ‌دنده فلزی، حلقهٔ خودکار).

صفحات بیرون نبرد:
- **هاب اردوگاه** تمام‌صفحه با آرت (نه لیست تنظیمات)
- دکمهٔ «نبرد» بزرگ حکاکی‌شده
- کارت‌ها / قهرمانان / نقشه به‌صورت اتاق‌های اردوگاه

داخل نبرد:
- بدون AppBar متریال
- بدون Card سفید
- فونت نمایش برای عدد آسیب (impact font)
- عدد آسیب شناور با drift فیزیکی

## ۹) صدا و حس وزن (بخشی از «واقعی بودن»)

بدون صدا، حرکت عکس می‌ماند.
- لایهٔ موسیقی بایوم (لوپ ۲۴–۴۰ ثانیه)
- whoosh wind-up، impact لایه‌لایه (فلز/گوشت/خاک)
- parry = «شینگ» واضح (درس E33: کیو صوتی از کیو شلوغ بصری بهتر است)
- UI: کلیک چوب/فلز نه blip موبایل

هدف حجم: SFX فشرده + ۱–۲ ترک موسیقی ≈ ۸–۱۵ MB اضافه.

## ۱۳) پروتکل حافظه / ضدلیمیت ورک‌اسپیس

1. هر نشست با خواندن **همین فایل** شروع شود.
2. تغییرات کد در ریپوی سورس (خصوصی) + **ریلیز APK اینجا**.
3. بعد از هر فاز: بخش «لاگ اجرا» پایین همین فایل آپدیت شود و پوش شود.
4. فایل حجیم (اسپریت، wav) در Release assets یا Git LFS — نه به‌صورت هزار فایل در ورک‌اسپیس موقت.
5. ورک‌اسپیس را خالی از آرت جنریت‌شدهٔ یک‌بارمصرف نگه دار.
